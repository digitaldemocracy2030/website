この章では、DD2030にどう参加し、何から始めればよいかを説明します。

## 「私は何をすればいいのか」

DD2030には、エンジニアだけでなく、さまざまなスキルや経験を持つ方が貢献できる場所があります。以下の表を参考に、ご自身の興味・経験に合った参加方法を見つけてください。

| 興味・経験 | 最初にできること | 関係する活動 |
| ----- | ----- | ----- |
| エンジニア | Issue確認、環境構築、バグ修正 | 広聴AI、いどばた、Coreloop |
| デザイナー | UI改善、利用者導線、説明資料 | 各プロダクト |
| 行政職員 | 利用場面や業務課題の共有 | ブロードリスニング、広聴AI |
| 研究者 | 事例・制度・評価手法の整理 | ブロードリスニング |
| ライター・編集者 | ドキュメントや事例記事の作成 | コミュニティ全体 |
| 地域実践者 | 地域課題を持ち込み、小規模実験 | Coreloop |
| 特別なスキルがない人 | テスト参加、イベント運営、議論への参加 | 各活動 |

## 参加のための具体的な情報

### Slackに参加する

DD2030の活動の中心はSlackです。まずはSlackに参加しましょう。

**Slack招待リンク：** https://join.slack.com/t/dd2030/shared_invite/zt-3bg5nmxiv-CB9LXLpvxH_JvJil_EPa_w

### 最初に見るべきチャンネル

Slackに参加したら、まず以下のチャンネルを確認してみましょう：

* **`#1_自己紹介`** — まずはここで簡単な挨拶と自己紹介をしましょう
* **`#0_全体お知らせ`** — 定例会やウェルカムミーティングの日程が流れます
* **`#7_雑談`** — イベント情報やちょっとしたアイデアを気軽に共有する場
* 興味のあるプロジェクトのチャンネル（例：`#2_開発_広聴ai`）を覗いてみる

### 知っておくべきこと

* **定例会はいつか** — 各プロジェクトの定例ミーティングの日程を確認しましょう
* **初心者向けタスクはどこにあるか** — GitHubのIssueに「good first issue」タグが付いているものを探しましょう
* **意思決定はどのように行われるか** — Slack上での議論を通じて、合意形成が行われています
* **「提案」から「実際の活動」へどう進むか** — まずSlackで提案し、共感する仲間を集め、プロジェクトとして動き出します
* **ボランティアとしてできる範囲** — 自分のペースで参加できます。無理のない範囲で貢献しましょう
* **責任を負うメンテナーとの違い** — 継続的にコミットできる方は、プロジェクトのメンテナーとしてより深く関わることもできます

## DD2030が求めている人

DD2030は、以下のような方の参加を求めています：

* **デジタル民主主義の究極目標に共感する方** — 「声を集めて終わり」ではなく、市民の意見を政策・法令・予算として実行し、社会の改善実感まで届けたいと考える方
* **「AIは合意の地図を描くことには長けているが、その地図の上でどこへ向かうかを決め、実際に歩き出すのは人間の仕事」** — この考えに共感し、「歩き出す人間」の一人になりたい方
* **多様な立場からの貢献を歓迎** — エンジニアだけでなく、行政職員、研究者、デザイナー、ライター、地域実践者、そして「特別なスキルがない」と思っている方も
